# 视觉语言与分镜

从原作分镜和实现提炼。参数是起步示例，可按新作品改写。

这些构图和材质用于表达具体动作。设计时结合 [motion-recipes.md](motion-recipes.md) 写出主体如何发展及留下结果，按 [transition-contracts.md](transition-contracts.md) 说明前后交接；持续观看的验收见 [aesthetic-validation.md](aesthetic-validation.md)。

## 编辑感的构成

| 组成 | 操作 | 叙事作用 |
|---|---|---|
| 版面骨架 | 页边、跨页中缝、图注、页码、目次、细线、裁切线、对位标 | 建立出版物秩序，随后撕裂它 |
| 字体关系 | 明朝叙述、黑体标记、大型展示字、衬线斜体与等宽字对照 | 文学、海报和技术注释的层次 |
| 横竖排对位 | 竖排与横向照片条带交叉，留出安静区域 | 文字参与空间，保持阅读方向 |
| 油墨限制 | 暖白纸、近黑主版、红/青绿专色，局部四色或原色照片 | 高潮可以突破色彩限制 |
| 印刷质感 | 网点、纤维、墨空洞、套印偏移、负片、湿纸 | 材质随情绪变化 |
| 编辑性照片 | 接触印样、近裁切、地平线对齐、遮挡、小图重复与大图 | 同一照片改变心理距离 |

参考色：纸 `#efebe2`、黑 `#1d1b1c`、红 `#e8352e`、青绿 `#00838a`。新主题重新选择有限色组。

为新曲记录色组与背景依据：哪种听感或用户指定情绪支持它，哪个段落改变色块比例，什么内容需要可读的负形。把用户方向、实际听辨与尚未验证的设计选择区分开。音乐风格不唯一决定颜色；用带音乐的样片检查配色、材质和速度是否共同成立。背景可以参与主体的流向、张力与遮挡，也可以在有意义的停留中稳定下来。

连续流动需要累计的发展，如轮廓卷折、展开长度或遮挡关系改变；小幅周期晃动本身不会产生动作结果。若设计要求字画随弯曲条带流动，除复用遮罩边界外，还要实现沿中心线/材料坐标的内容映射，检查是否仍像矩形画面被裁切。该映射是新方案的实现要求，不属于原例已证明的通用变形功能。

大字与小图注并置，细线指向物体或裁切位置，保留阅读锚点。版式在杂志秩序、接触印样和破碎条带之间变化。质感参数分阶段出现，避免每帧全部开启。

## 意识流的意象链

为反复出现的意象记录初次含义、回归时的改变、最终回收。例如：

```text
眼睛：观察窗口 → 负片中的缺席 → 进入空间的通道
手：接住对象 → 镜像记忆 → 被环境吞没
圆形：标注圈 → 镜头/月亮/孔洞 → 结尾的单点
```

新作品可用站台、窗户、雨迹、信纸、皮肤等重建关系，身份和音乐意义来自用户作品。

- 预示：提前出现后文意象，短暂但有回收。
- 回忆：旧照片负片、镜像、重裁切后再印。
- 联想剪辑：保持轮廓、地平线、方向或色块位置，切换对象。
- 字形动作：原例可核实的是逐字显现、词组下沉、删改线、轮廓回声及字形遮罩。拆成笔画/流线或拓扑形变可作为新增方案，需另行实现；保留正常阅读时段。

原作闪帧持续一个十六分音符，91 BPM 时约 0.165 秒。用音乐单位编排，换曲后换算秒数。潜意识插入不等于持续高频闪烁。

## 平面变成空间

1. 窗：纸面挖孔，孔后有空间，孔形由意象或音符决定。
2. 照片：实时空间印成照片，放入跨页或网格。
3. 物体：刚看到的版面变为有位置的卡片，漂移、下沉、翻转。
4. 光：纸上文字转为镜头前的光，图注投影到世界对象。
5. 尺度反转：网点成为粒子，图注的圆成为天体。

保留一个识别锚点跨越转换，如同一照片、页码、标注或圆窗，让观众感到同一事物改变了材质。

## 音乐成为版式

| 已验证的音乐结构 | 对应版式 |
|---|---|
| 4/4 的 3+3+3+3+4 十六分组 | 五条或五机位，长度按分组比例 |
| 5/8 | 五条横带；十六分细组可为 4+6 / 4+3+3 |
| 5/8、5/8、5/8、6/8 循环 | 10:10:10:12 宽的跨页格子 |
| 短小节、停顿 | 版式压缩、悬停、留白 |
| 长音/噪音墙 | 字符延伸、镜头进入空间、照片纵深堆叠 |

先核对音乐结构，稳定四拍作品可用自己的映射。

## 分镜表

| 时间/音乐锚点 | 情绪与意象 | 版式与材质 | 镜头/转场 | 动作与回收 |
|---|---|---|---|---|
| 引子第一强拍 | 首次出现窗 | 留白单页、单色图 | 俯视缓推 | 墨版显影，后文开孔 |
| 主歌关键字 | 观察转为被观察 | 近裁切、竖排 | 沿轮廓硬切 | 图像成为孔洞 |
| 第一高潮 | 意象失控 | 文字成光、照片成物体 | 平面穿入 3D | 深度、尺度、机速一起增加 |
| 第二高潮 | 意象失去身份 | 负片、缺席、破碎跨页 | 原机位反向 | 更大的环境变化 |
| 尾声 | 余像 | 纸面合拢 | 远去/俯视 | 减色减元素，以单点/单字回收 |

可迁移的是「回归但改变」与「材质转换」，海、血月、东京和原作歌词按新主题重选。
