# 媒介选择与风格语法

## 有意义的路线比较

比较对象使用同一意象、近似构图和同一情绪任务；不要把“好看的动漫人物”与“随手找的城市照片”直接评分。

| 路线 | 擅长的表达 | 需要设计的条件 | 常见失败 |
| --- | --- | --- | --- |
| 写实摄影 | 具体生活经验、身体触感、观察距离与可信细节 | 机位、镜头感、照明动机、色温、曝光、人物一致性、时间/地点 | 所有图都像同一柔光广告；只有散景与皮肤特写 |
| 动漫/动画美术 | 角色情绪、清晰剪影、夸张形态与可绘制动作 | 人物比例、发型衣着、线条系统、上色方式、背景绘法、表情尺度 | 立绘海报滑动；泛化大眼人物与饱和星空脱离歌曲 |
| 手绘/版画/拼贴 | 内在冲突、非写实联想、图底互换与材料变化 | 边缘、笔触方向、色块结构、扫描质感尺度、拼接原则 | 无差别脏纹理；抽象到失去可识别对象 |
| 混合 | 现实痕迹进入主观世界、媒介变化成为叙事 | 一个主媒介；其他媒介的角色、统一处理与转换桥梁 | 摄影、动漫、3D 各自使用不同色光，像拼素材 |

有既定方向时不重新做全路线竞赛。用户允许改变风格时给出推荐与可验证理由。没有足够信息也可以先选一条可逆方案，标明选择性质。

## 写成可执行的视觉语法

| 维度 | 决策应具体到 |
| --- | --- |
| 轮廓 | 主体边缘软/硬、线条粗细和断续位置；剪影在缩小后是否仍能辨认 |
| 明暗 | 主体与背景的层级、黑块面积、亮点位置；避免每张图都做完整光影戏 |
| 色彩 | 主色、辅助色、叙事强调色及各自使用场景；实际并置检查，不只列十六进制 |
| 构图 | 主体锚点、移动方向、图底关系、地平线高度、留白用途、裁切规则 |
| 人物 | 年龄呈现、比例、衣着、身份特征、观察距离与回避哪些表情/姿势 |
| 材料 | 绘画纸、油墨、摄影颗粒等各自的空间尺度与出现阶段；保留平坦区域 |
| 空间 | 正交/透视、层次数量、近远边缘与对比；真实几何如何匹配 2D 的哑光表面 |
| 变化 | 同一风格允许哪些变化，什么保持不变；角色改变动作而非换一个脸 |

色彩可从两个有功能的色组起步，例如“日常记忆”和“情绪破口”，数量与比例由作品决定。纸白、茜红、墨蓝都不是跨歌曲的强制配置。

## 一致与丰富分开设计

保持角色身份、轮廓语言、黑位、主要光向与空间比例；在景别、主体有无、取景、负形面积、局部纹理与重音色面积上变化。素材库应同时有可停留的安静图与可切割的高信息图。

从“对象不同但图像相似”中跳出来：人物、手、嘴三张柔焦近照可能视觉上仍只有一种材料；同一个窗的全景、剪影、空洞、反射痕迹和单色轮廓能形成更多有效变化。

## 混合媒介的桥梁

- 先明确摄影承担什么：物理痕迹、记忆证据、人物身份或节奏性插入。
- 用共同轮廓、构图、对比层级与有限色组连接媒介；转为网点/阈值图只是可选处理，不能掩盖不合适的题材。
- 通过同一轮廓的照片→遮罩→绘制线→空间开孔连接，而非无理由换图。
- 真实 3D 的透视和遮挡可保留，材质改为与二维画面一致的哑光、简化明暗和克制反射。决定这些改动时写明需要实现的着色器行为。

## 风格种子

先选能代表全套的主图、一张局部/材质图，以及一组有共同锚点的变化图。若尚未选择媒介，少量同构图试样用于比较；不要一开始各路线生成几十张。

把试样放入最终版面，看主体、底部歌词和重要负形是否竞争，再做短动作。静帧只能验证画面关系，不能证明流动、情绪推进或转场成立。
