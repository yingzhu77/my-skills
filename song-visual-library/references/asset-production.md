# 生成、搜索与绘制

## 获取方式按任务选择

| 需求 | 优先方式 | 理由 |
| --- | --- | --- |
| 同一人物/机位的在场与缺席、独特情绪场景 | 生成或参考图编辑 | 易于围绕选定母版控制变化 |
| 真实街道、材料结构、手势观察与具体摄影证据 | 用户素材或来源清晰的搜索 | 保留具体性；也可仅作观察参考 |
| 精确窗框、遮罩、字形、切割轮廓与可变图形 | SVG、Canvas、手绘或代码几何 | 保持坐标与动画可控性 |
| 碎片、光痕、纸墨扫描等非规则位图 | 生成、实拍或扫描 | 自然局部差异有用，但需匹配纹理尺度 |

不为可直接绘制的矩形窗框请求一张包含错误透视的海报。不要指望生成图中的文字承担准确歌词排版。

## 提示词包含可检验的约束

按下面的信息组织自然语言，不必依赖特定模型语法：

1. **用途与文件类型**：这是背景、独立主体、前景遮挡还是同机位替换图；用于何种裁切/动作。
2. **统一风格块**：媒介、轮廓、用色、明暗与纹理规则，复用选定方向中的同一版本。
3. **主体与状态**：对象身份、动作阶段、在场/缺席、破损范围等。
4. **构图与锚点**：比例、视角、主体相对位置、地平线、边缘余量、重要留白。
5. **可用性**：透明背景、补齐遮挡区域、不含文字、背景独立、适配的最终尺寸。
6. **排除项**：只写与本方向有关的错误，例如商业美妆光、巨月、霓虹招牌；不要堆通用负面词。

实际请求应填写具体对象与约束，不把模板变量原样交给图像工具。

示例骨架：

> 一张用于 16:9 MV 的独立背景板，比例 16:9，目标 2560×1440。使用已确定的手绘平涂与干笔边缘：低饱和灰绿远景、炭黑近景、少量米白亮点。固定低视点，地平线位于画面下三分之一；右侧留出连续的低信息区域供人物移动。只画环境，不画人物与前景窗框，建筑轮廓在两侧超出取景边缘，方便横向移动时延展。图中不出现文字、水印或已排版歌词。不要商业摄影光晕和均匀散景。

示例颜色与构图不作为默认方向。

## 比例与尺寸

分别记录生成请求比例、实际返回尺寸、最终使用区域。工具支持的尺寸可能与目标不同；按已知能力选择相近尺寸，再检查裁切，不能承诺未支持的像素值。

- 16:9 适合全屏环境；4:5/3:4 常用于人物与竖向主体；1:1 可用于材质；横条比例服务跨页或横向遮挡。
- 独立人物等透明板的边界框也需有余量，头发、手指或衣角不能贴边。
- 可移动背景需要比实际视口更宽/高，或提供可信的边缘延展；变大放大不等于新增真实细节。
- 纹理数组可统一工作分辨率，原图与有效比例仍需保留；在几何中恢复比例或裁切，禁止无理由拉伸。

## 保持身份与机位

有选定母版时，通过参考图编辑制作状态，明确只改变哪些元素。最稳妥的在场/缺席组合通常是固定背景加独立人物/反射层，而非重新生成两张完整画面。

记录人物身份锚点、视角、光向、地平线、主体边界框与窗口角点。新变体验收时检查这些关系。状态图不能自动当作动画中间帧：需要时间上的连续形状或另行实现形变。

透明输出要真实 alpha。白底/棋盘格画进图片都不等于透明；半透明头发和玻璃还要检查在明、暗两种背景上的边缘。

调用可用图像工具时依其规范生成/编辑，尊重用户的工具选择。若内部工具不暴露模型，就记录工具名称与“模型未公开”，不冒称使用网页上的某个模型。图像编辑使用指定图像工具；代码/SVG 绘制是独立制作路线，不用它偷偷替代用户要求的图像编辑。

## 搜索简报

每次搜索先指定视觉任务：主题、尺度、机位、材料、光线，以及“用作参考”或“用作成片素材”。从具体可观察词组合查询，例如“condensation glass backlit macro dark background texture”；形容词“忧伤、电影感”通常不能可靠筛选结果。

浏览原始来源页，记录作者、页面 URL、允许使用的依据和取得日期。标签、搜索筛选与缩略图不能证明授权。缺少证据的图可留作参考候选，不直接标为已许可成片素材。搜索不到适配素材时改为生成或绘制，并说明选择依据。

## 原生绘制适合承担的工作

为窗框、眼/口的负形、纸裂缝、呼吸线与抹除路径建立可参数化几何，保存锚点或路径。主体、遮罩与描边尽可能共用几何函数；它们的运动关系属于后续实现合同。

先保留不带颗粒的清晰版本。若需要版画效果，在可辨认的形状上添加局部缺墨，而不是用随机噪声覆盖整个画面。
