# 从歌曲到设计依据

## 建立证据层

| 输入 | 可以支持 | 仍需确认 |
| --- | --- | --- |
| 用户提供的歌词、偏好、BPM | 语义顺序、用户方向、名义速度 | 演唱时间、录音拍点、歌曲的唯一视觉解释 |
| 实际听辨并记录具体区间 | 人声距离、配器质感、留白、展开与收束的体验 | 未听到区间的结构与乐器 |
| 波形、RMS、频谱、混音起音 | 能量或频段变化、剪辑候选 | 乐器身份、主观情绪、确认鼓点与小节强拍 |
| 已有成片与参考 | 构图、动作、材质与实现的观察 | 不能只凭 README 的风格词认定实际效果 |
| 导演选择 | 视觉隐喻与形式规则 | 应作为创作解释，不标成测量事实 |

工具不能直接听辨时，仍能分析歌词、已有观测与用户反馈。明确这一限制，不把“我读到了音频文件”写成“我已听清歌曲”。

## 形成歌曲肖像

用少量有证据的句子概括，不填满通用风格形容词：

- **叙事矛盾**：谁在对谁表达？表达在保护、接近、拒绝还是反过来伤害自己？例如“越想保存记忆，画面越被擦掉”。
- **情绪运动**：压抑到外放、疏离到亲密、平静表面下的紧张，分别在哪段有依据？不要让全曲只有“悲伤”一个状态。
- **声音触感**：已听辨的干/湿、颗粒/平滑、疏/密、近/远、短冲击/长延续；这些提供边缘与运动的选择依据，不直接指定颜色。
- **观看距离**：观众是旁观人物、进入人物视野，还是观看不稳定的记忆？这影响正脸、背影、局部、空场的比例。
- **段落差异**：素材在推进中改变什么？尺度、背景信息量、色块面积、边缘完整度或空间深度，比“高潮多加特效”更可执行。

歌词作为意象来源时，从关系与动词提取动作。唱爱可转为接近后相互遮挡；遗忘可转为同一机位缺席；寂静可转为主体不动但边缘密度上升。避免每个名词都配一张字面插图。

## 写一条设计命题

格式：**谁/什么对象，在什么观看关系中，经历怎样的变化，用什么媒介使变化可见。**

例如：记忆中的人物逐渐从同一扇窗里消失，城市的灯只剩印刷空洞；用手绘轮廓、摄影痕迹和可打开的纸面空间呈现。示例不是所有夜曲的默认主题。

这条命题应能决定至少三件具体事：保留哪类素材、删除哪类题材、同一意象如何变体。若只决定“蓝色、忧伤、电影感”，仍不足以指导素材生产。

## 审美假设的验证

给每条主要选择记录依据与一个可观察问题：

| 选择 | 依据类型 | 验证问题 |
| --- | --- | --- |
| 人物不正视镜头 | 歌词解读/观看距离 | 观众是否关注关系与缺席，而不是肖像吸引力？ |
| 冷灰主色、少量暖色破口 | 导演选择与听感候选 | 暖色是否帮助段落展开，还是像另一个广告场景？ |
| 软边人物、硬边窗框 | 主体与界面的关系 | 动画与小尺寸预览中两者是否容易区分？ |

颜色与流派不是一一对应。让风格种子在实际歌词版面与一小段运动里接受验证，并明确是否完成了带音乐观看。
