# 筛选、替换与动作接口

## 素材覆盖矩阵

先按片段设计需要列行，再填素材。常见职责是：

- 主意象：可追踪的窗、人物、对象或形状。
- 环境：安静背景、距离层、空间进入后的世界。
- 主体：独立人物、手势、阴影或几何。
- 遮挡与过渡：前景、开孔、抹除、折叠的边界。
- 材料与重音：摄影痕迹、局部墨块、色彩破口。

不是每段都需要所有类别。对缺项说明它会阻止什么动作；没有用途的美图不因“丰富素材”被加入。

## 分三层审查

**单图。** 对象是否清楚？缩小后轮廓是否保留？明暗主次是否明确？人物与手势是否可信？是否有错误透视、文字、边缘或商业摆拍感？实际裁切是否伤及主体？

**全套。** 联系表中是否只有同一种景别与同一类光线？主色、黑位与笔触是否属于同一世界？变化图是否保留身份？是否有足够安静区与不同尺度？哪些图可以相互接续？

**动作。** 放入实际版面并检查一个完整动作及一次交接：有无背景洞、白边、比例拉伸和贴边截断？遮罩与主体能否重合？近远层移动是否有真实的观看依据？图像切换是否留下可追踪锚点？

连续样片与静帧分别记录。机器可检查尺寸、alpha 和加载，但不能替代上述判断。

## 接受与淘汰

记录具体决定：

| 决定 | 示例理由 | 后续 |
| --- | --- | --- |
| 接受 | 剪影清晰、同一机位、留白支持文字；角色层可独立移动 | 放入实际动作检查 |
| 重做 | 轮廓正确但肤色/材质过于摄影，破坏主媒介 | 使用母版重新绘制，保留边界框 |
| 缩小用途 | 大图细节空泛，但局部玻璃痕迹可作为遮罩参考 | 仅保留局部角色，不继续重复全图 |
| 淘汰 | 重复已有功能、与歌曲命题无关、姿态像产品广告 | 从新活跃库排除；检查引用后处理文件 |

一个失败样例不能产生“所有嘴部图片都禁用”之类通用规则。是否需要这类素材取决于作品观看关系。

## 动作合同

为会动的素材记录必要字段：

- `family_id`、`state` 与下一状态；例如同窗的在场→缺席。
- 画布比例、原始尺寸、主体边界框、锚点与可用裁切。
- 底图、主体、前景、反射/遮罩；哪层必须补绘被遮挡区域。
- 运动需要的额外画面、透明边缘、重叠区域。
- 共享的轮廓/路径/UV/世界平面；在哪个变化中仍需重合。
- 当前职责：全屏停留、近处掠过、空间纹理、开孔边界或局部插入。

在场→缺席优先关闭人物层、保留底图；手势变化需要同身份的姿态与明确的连接方式；声线扩展使用可生长路径；进入窗的动画让开孔、框与相机共享几何。新图片不能代替这些实现。

## 安全切换活跃库

1. 将筛选状态写入索引，旧版仍可复现。新制作使用单独活跃库或新版本目录。
2. 接受替代品，修改引用与必要构图，检查相关完整动作。
3. 用文件名、素材 ID 和动态加载路径检查引用；`rg` 结果只是一部分证据，仍要检查 manifest 与运行时资源加载。
4. 已被替换且可恢复的旧素材从新活跃库排除或移入归档；确实需要物理删除时确认目标与引用。需要复现的旧交付不删除其输入。

不要把“审美上淘汰”与“已从磁盘删除”混报，也不要让 skill 的清理步骤扩大为删除用户素材目录。
