# 素材库记录与接续文档

按任务大小选用下面字段。简短提示词任务无需创建完整制作目录。

## 美术简报

保存一份 `ART-DIRECTION.md`，包含：

1. 工作范围、输出比例、用户约束与已确认事实。
2. 歌曲叙事/声音依据及未确认项。
3. 一条设计命题。
4. 已选方向，或少量路线的比较与推荐。
5. 轮廓、色彩、明暗、构图、人物、材料和空间语法。
6. 素材家族、状态及段落中的改变。
7. 风格种子和实际动作的验收标准。

制作中的个别歌曲简报放在制作目录，通用 skill 不内嵌用户歌曲与历史绝对路径。

## 素材索引

可用 JSON、表格或现有项目格式。JSON 示例字段如下；实际执行时用具体值替换示例内容，未生成文件不能标为接受：

```json
{
  "schema_version": 1,
  "direction_id": "selected-direction",
  "assets": [
    {
      "id": "window-person",
      "family_id": "window-memory",
      "role": "subject",
      "state": "present",
      "status": "planned",
      "path": null,
      "source": {"method": "generate", "reference_ids": []},
      "request": {"ratio": "3:4", "target_pixels": [1536, 2048]},
      "actual": null,
      "alpha_required": true,
      "anchor": {"units": "normalized", "point": [0.5, 0.75]},
      "next_state": "absent",
      "motion_use": "fade subject; preserve independent background",
      "review": {"decision": "pending", "reason": null},
      "used_by": []
    }
  ]
}
```

建议状态：`planned`（未取得）、`candidate`（待评）、`accepted`（可用于本方向）、`rework`（需重做）、`retired`（退出活跃库）。使用其他项目既有状态也可以，只要含义清楚。

取得后记录实际尺寸、alpha 观测、文件校验值、工具/模型已知信息、原始来源页、生成参考和处理历史。搜索素材的来源与授权证据是两个字段；生成素材也不伪称实拍。视觉审查理由应比“高质量”具体。

`path` 用相对制作根目录的路径；计划行保持 `null`。保留原图与使用版的对应关系，不把未经核实的目标比例写成实际尺寸。

## 提示词包

按家族分组，包含统一风格块、每张图的任务、比例、透明度与连接关系。母版确定后把具体母版引用写入变体提示词，避免继续各自独立生成。目标像素是制作目标，实际工具输出另记。

## 新窗口接续

保存 `HANDOFF.md`，让没有聊天历史的下一位执行者能工作：

- 当前用户目标、已有授权、偏好和不能被泛化的反馈。
- skill 入口、现有可运行版本、源歌曲、对齐与许可记录的位置。
- 哪些是已完成事实，哪些是推荐，哪些尚未生成/观看/确认。
- 已评素材的保留、重做与退出决定，当前引用是否允许物理清理。
- 下一步先读什么、先做什么，风格如何选择，何时扩展与验收。
- 本地服务入口与启动方式；依赖路径仅作为本机信息。
- 仓库只保存通用 skill，制作和媒体放在指定工作区；保护无关用户修改。

不要在接续文档里虚构已完成生成或批准，也不要把旧聊天中的候选时间升级为确认事实。
